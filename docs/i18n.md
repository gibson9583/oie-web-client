# Internationalization

The administrator supports English (`en`) and Simplified Chinese (`zh-CN`). Choose a language on the login screen or in Settings → Administrator. The browser preference `oie-locale` applies across engines and users in that browser. Switching checks unsaved work before writing the preference and reloading. Other open tabs keep their current language until their next reload.

## Runtime contract

The small bootstrap initializes `core/i18n` and loads the host catalog before dynamically importing the application. This order is required: navigation, columns, data types, and plugin registrations capture labels at module evaluation time. Use the shared `@oie/web-ui` exports or `platform.i18n`; do not bundle another runtime.

English ICU messages are the source keys:

```ts
import { t, tc, tx, scope, formatNumber, formatList } from '@oie/web-ui';

t('Saved {name}', { name: user.name });
t('{count, plural, one {# channel} other {# channels}}', { count });
tc('verb', 'Open');
tx('Read <link>the guide</link>', { link: chunks => <a href="/help">{chunks}</a> });
```

Use complete literal messages, named values, ICU plurals/selects, and semantic rich tags. Double literal apostrophes in ICU source (`Don''t Save`). `t` returns plain text; `tx` returns strings and the elements supplied by trusted code. Catalog strings never become HTML. Context keys use a U+0004 separator (`verb\u0004Open`).

The page locale is immutable. The public API includes `t`, `tc`, `tx`, `scope`, `locale`, `locales`, `setLocale`, `formatNumber`, `formatList`, and `compareText`. `setLocale` resolves false after cancellation, a concurrent switch, an unsupported locale, or unavailable storage. A successful switch reloads the page; a same-language request only persists the preference.

Locale negotiation respects browser preference order and script. `zh`, `zh-Hans`, and `zh-SG` select Simplified Chinese; `zh-Hant`/Taiwan/Hong Kong do not. A missing, invalid, or slow host catalog falls back to English after at most two seconds. Missing or invalid individual translations fall back to English.

## Plugin authors

Localization is optional. It does not change the API version, engine requirements,
or your plugin's existing `oie.apiMin`. Declare a catalog relative to `plugin.json`:

```json
{
  "id": "example",
  "client": { "entry": "web/plugin.js" },
  "i18n": { "zh-CN": "i18n/zh-CN.json" }
}
```

```ts
export function register(platform) {
  const title = platform.i18n?.scope('example').t('Example tools') ?? 'Example tools';
  platform.registerNavItem({
    id: 'example', path: '/example', label: title,
    section: 'example-tools', sectionLabel: title
  });
}
```

The host awaits each catalog before importing that plugin. Resolution is plugin → host → English, including invalid-message fallback. Catalog failure does not disable the plugin. Catalog URLs must be relative JSON paths without traversal, query strings, or encoded separators. Engine catalogs use the same session fencing, credentials, no-store policy, and CSRF header as engine API requests, including WAR extension paths. An older response cannot replace a newer catalog for the same plugin ID.

Keep `section`, navigation IDs, routes, setting panel `id`/`taskGroup`, pane keys, and RBAC group names stable. Put translations in `sectionLabel` and other display labels. Existing plugins without catalogs continue to work in English. External plugin repositories are independent follow-up migrations.

## Data boundary

Translate interface prose and known built-in labels at render boundaries. Never translate user-entered names, imported content, engine diagnostics, scripts, metadata keys, transport names stored in models, enum values, country/role values, URLs, XML element names, IDs, exports, or clipboard payloads. Options must have independent `value` and `label` fields.

Use `Intl` formatting for displayed numbers and lists and `compareText` for human-readable sorting. Engine/API timestamps and the administrator's displayed `YYYY-MM-DD HH:mm:ss` shape remain unchanged. Calendar labels use the active language. Chinese Monaco NLS comes from the exact installed Monaco version, with a recorded content hash; a stalled NLS load leaves the usable textarea editor.

All Enter-to-commit input handlers must use `isCommitEnter`. It rejects native/React composition events and key code 229, including Safari's composition-end ordering.

## Catalog maintenance and checks

- `npm run i18n:extract` updates English source references in `client/locales/messages.json`.
- `npm run i18n:check` checks extraction drift, ICU argument/tag/select contracts, coverage, and the raw-literal ratchet. Missing translations are reported as coverage, not fatal; malformed contracts fail.
- `npm test` includes these checks and runtime/tooling regression tests.
- JSX prose is enforced by `react/jsx-no-literals`. Engine-extracted API reference text and code samples remain engine-owned content. Locally authored mapping labels and completion hints use the host catalog. Non-JSX candidate counts are in `tools/i18n-literals.json`. Review each intentional protocol/code/identifier exception before using `--record-reviewed`; never reset the baseline just to silence a new label.
- `npm run build:i18n-test` enables `?locale=en-XA`. It accents, brackets, and expands literal text while preserving arguments and rich elements. Ordinary production builds ignore that query.
- `E2E_PSEUDO=1 npx playwright test 'e2e/i18n[^/]*\.spec\.ts$' --project=ui` checks the test bundle. CI runs both packaged production and development pseudo builds separately, retaining separate evidence.

The Simplified Chinese catalog is an initial translation. Native-speaker terminology and release acceptance remain a release follow-up, not a claim made by the automated checks.

## Deployment fonts and older plugin hosts

Minimal Linux and kiosk images should install Noto Sans CJK SC (or another Simplified Chinese font). The UI uses system CJK fallbacks rather than downloading fonts; verify the deployment image has glyph coverage. Chinese section headings use 12px text without Latin letter spacing. Known English engine log blocks carry `lang="en"`; user-entered names and messages retain their original content.

Plugins supporting hosts without localization must avoid static imports of the new
i18n exports: those hosts cannot resolve them. Check `platform.i18n` inside
`register`, as in the [compatibility example](../web-administrator/PLUGINS.md#localization),
and retain an English path when it is absent. The example fallback supports simple
named placeholders only. For ICU plurals, selects or rich text, branch on the
capability and provide equivalent English rendering in the fallback; do not pass
ICU syntax to the simple placeholder shim. Plugins shipped with this host may use
its shared `@oie/web-ui` exports directly. No version bump is needed in either case.
